# Python 100 Programs

My Python solutions to the "100 Programs to Build Your Problem-Solving" sheet by codeWithShivah. I am doing this to build problem-solving skills for data science.

## Levels

| Level | Topic | Programs |
|---|---|---|
| [1](./level-1-warmup) | Warm-up | p1 to p[x] |
| [2](./level-2-conditions) | Conditions | p[x] to p[x] |
| [3](./level-3-loops) | Loops | p[x] to p32 |
| [4](./level-4-digits) | Digits | p33 to p43 |
| [5](./level-5-number-classification) | Number classification | p44 to p56 |
| [6](./level-6-series-patterns) | Series and patterns | p57 to p67 |

## Naming convention

Files are named `p<number>_<verb>_<what>.py`, for example `p54_check_prime.py`.

## How to run

```bash
python level-4-digits/p35_sum_of_digits.py
```
